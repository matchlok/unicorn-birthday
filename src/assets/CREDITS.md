# Credits

Unicorn Birthday Bash was made for one little girl's birthday.

## Sounds and music

Every sound and the music are synthesized live in the browser with the Web Audio API (see src/engine/audio.ts). There are no audio files, no samples and no recordings, so there is nothing to license.

## Art

All pictures are self-made: the unicorn, the party hub, the creatures, the karts, the train maze and Red Rocks Romp are drawn in code as SVG, canvas and three.js shapes. There are no image or 3D model files from anyone else.
